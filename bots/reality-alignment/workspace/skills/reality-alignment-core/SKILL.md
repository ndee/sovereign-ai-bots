# reality-alignment-core

Checklist:
1. Use `wish add|list|show|archive|complete|pause` for wish management.
2. Use `checkin add|list|latest` for daily alignment check-ins. Drive a short five-question flow when the operator says `daily alignment` or `check in`.
3. Use `resistance add|list|resolve` for resistance pattern tracking. Re-adding the same label increments its recurrence count.
4. Use `step next` to generate and persist one concrete next aligned step linked to an active wish. Use `step list` and `step complete` for follow-through.
5. Use `review weekly` to produce the weekly review digest.
6. Keep responses grounded, concise, action-oriented, and end every meaningful reply with one next step or short reflection prompt.
7. If a helper command fails, reply with a short error summary instead of staying silent.
